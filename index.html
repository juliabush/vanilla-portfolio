Blog Aggregator

Why I created this project

I had previously worked with the Prisma ORM but wanted to explore Drizzle after hearing about its lighter-weight, more modern approach. This project also gave me solid practice working with PostgreSQL and designing relational tables for users, feeds, and follows, which I found especially rewarding as a way to build out a full CRUD-style backend from scratch.

What this project does

  • Provides a command-line interface that lets users register, log in, follow feeds, and browse aggregated posts.
  • Uses a clean, middleware-based command system in TypeScript to keep logic modular and easy to extend.
  • Stores and manages data in a normalized PostgreSQL database using Drizzle ORM, with proper relationships and deduplication.
  • Continuously pulls in and updates RSS feeds in the background to keep posts fresh and up to date.

Why I created this project

I enjoy reading Tarot in my free time and interpreting the meaning behind different spreads. This project grew out of that interest alongside a desire to experiment with the ChatGPT API by building a lightweight AI-powered wrapper.

What this project does

  • Generates interactive Tarot readings through a Next.js and React-based web application.
  • Streams AI-generated interpretations in real time, allowing responses to appear naturally as they are created.
  • Uses a custom typewriter-style renderer to display text incrementally for a smoother reading experience.
  • Presents readings with animated Tarot cards and modal-based results using a polished, reusable UI.

Pokedex

View Website

Why I created this project

I loved playing with Pokémon cards as a kid, and when I discovered how extensive and well-designed the PokéAPI is, I wanted to build something with it. This project grew out of that nostalgia alongside an interest in experimenting with modern frontend technologies like React Three Fiber and Three.js.

What this project does

  • Simulates a Pokédex experience where users can attempt Pokémon captures using a fully animated 3D Pokéball.
  • Runs a Node.js and Express backend that manages game logic, in-memory state, and PokéAPI data with caching and tested endpoints.
  • Demonstrates a production-ready deployment with a Dockerized backend on AWS EC2 and a Vite-powered frontend deployed on Vercel.

Asteroids

View Website

Why I created this project

I was inspired by browser-based multiplayer games like Agar.io and Slither.io and wanted to create a real-time multiplayer experience of my own. After noticing the lack of a modern, in-browser version of the classic Asteroids arcade game, I decided to build one from scratch.

What this project does

  • Runs a server-side Asteroids game simulation using Python and Pygame, handling physics, collisions, and player input in real time.
  • Streams live game state updates to the browser over WebSockets to support smooth, low-latency multiplayer gameplay.
  • Renders the game in the browser with a responsive HTML and CSS frontend built using clean, maintainable styling practices.
  • Uses automated deployments with GitHub Actions to keep the AWS-hosted backend up to date and production ready.

Why I created this project

I took on this project to better understand how the DOM is structured and how nested hierarchies are built under the hood. I was especially drawn to the idea of writing code that could generate an entire website on its own, and found the process surprisingly fascinating and meta.

What this project does

  • Generates full HTML pages from Markdown files using Python
  • Uses a custom Markdown parser and simple HTML node system
  • Automatically walks through folders to build a complete static site
  • Includes unit tests and CI checks to ensure everything works as expected
